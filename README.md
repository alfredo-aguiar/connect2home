# connect2home

This project presents an interactive dashboard analysing three years of feedback from Connect 2 Home Gold Coast (2024–2026). The dashboard combines survey data, qualitative responses and community impact metrics to explore changing service needs, participant experiences and lessons for future events. It was developed as both an evaluation tool for stakeholders and a data storytelling portfolio project.
